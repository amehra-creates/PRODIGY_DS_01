# PRODIGY_DS_01

## Task 1: Histogram Visualization

This repository contains the solution for **Task 1** of the Prodigy InfoTech Data Science Internship.

### 📌 Objective
Create a bar chart or histogram to visualize the distribution of a continuous variable, such as ages in a population.

### 🛠️ Approach
- Generated 100 random ages between 18 and 60 using **NumPy**.
- Plotted a histogram using **Matplotlib**.
- Added labels and a title for clarity.

### 📊 Code Explanation
1. **Import libraries**: `matplotlib` for plotting, `numpy` for generating random numbers.  
2. **Generate data**: Created 100 random ages to simulate a population.  
3. **Plot histogram**: Grouped ages into ranges (bins) and displayed counts.  
4. **Add labels/title**: Made the chart understandable.  
5. **Show chart**: Displayed the histogram in a pop-up window.

### 🎨 Output
The histogram shows how many people fall into each age group. Taller bars indicate more people in that age range.
